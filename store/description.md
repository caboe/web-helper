## Ausführliche Beschreibung (Detailed Description)

### Deutsch

**Web Helper AI** verwandelt dein Browser-Side-Panel in einen persönlichen KI-Assistenten für die aktuelle Webseite: Sende Inhalte – einen markierten Ausschnitt oder die ganze Seite – an deinen eigenen LLM-Endpunkt und lass das Modell direkt auf der Seite arbeiten.

#### Was kannst du damit tun?
- **LLM-Endpunkte verwalten**: Lege beliebig viele Endpunkte an (OpenAI, Anthropic, OpenRouter, DeepSeek, Kimi, Qwen, Gemini, Mistral, Groq, lokale Server wie Ollama …) inkl. API-Key, Modell und Format. Praktische Provider-Vorlagen füllen alle Felder automatisch vor – du musst nur noch deinen API-Key eintragen.
- **Systemprompts verwalten**: Speichere wiederverwendbare Anweisungen (z. B. „Formular-Assistent“, „Zusammenfassen“, „Übersetzen“) und wähle sie pro Anfrage aus.
- **Inhalte senden**: Markiere Text auf der Seite und sende den Ausschnitt – oder schicke die ganze Seite als Markdown-ähnliche Extraktion. Umschalten per Toggle.
- **Tool-Calling auf der Seite**: Das Modell kann selbstständig auf der Seite agieren – Formularfelder ausfüllen, Elemente klicken, Text ersetzen oder Inhalte lesen. So entstehen echte Workflows: „Fülle das Formular mit den Daten aus meiner Markierung.“
- **Ergebnisse nutzen**: Antwort kopieren oder direkt an der Markierung in die Seite einfügen. Ein Live-Log zeigt jeden Tool-Aufruf.

#### So funktioniert es
1. Öffne das Side-Panel über das Toolbar-Icon (auf älteren Chrome-Versionen öffnet sich automatisch ein Popup).
2. Lege unter „Endpunkte“ deinen LLM-Endpunkt an (Vorlagen helfen).
3. Markiere Text auf einer beliebigen Webseite und sende ihn mit dem gewünschten Systemprompt.
4. Verfolge die Tool-Aufrufe live und füge die Antwort bei Bedarf direkt in die Seite ein.

#### Datenschutz & Sicherheit
- Alle Daten (Endpunkte, API-Keys, Prompts, Einstellungen) liegen **ausschließlich lokal** in deinem Browser (chrome.storage).
- Es werden **keine Daten an Dritte** übertragen. Deine Anfragen gehen direkt von deinem Browser an den von dir konfigurierten Endpunkt.
- API-Keys verlassen deinen Browser nie.
- Die Extension benötigt Zugriff auf alle Webseiten („<all_urls>“), um DOM-Tools auszuführen und beliebige, selbst konfigurierte LLM-Endpunkte zu erreichen.

#### Hinweise
- Für das Side-Panel wird Chrome 114+ (Permission seit 116) empfohlen; ältere Versionen nutzen automatisch das Popup.
- Die Qualität der Ergebnisse hängt vom gewählten Modell ab. Lokale Modelle (z. B. über Ollama) werden ebenfalls unterstützt.

### English

**Web Helper AI** turns your browser's side panel into a personal AI assistant for the current website: send content – a marked selection or the whole page – to your own LLM endpoint and let the model work directly on the page.

#### What can you do?
- **Manage LLM endpoints**: add any number of endpoints (OpenAI, Anthropic, OpenRouter, DeepSeek, Kimi, Qwen, Gemini, Mistral, Groq, local servers like Ollama …) including API key, model and format. Handy provider templates pre-fill every field – you only add your API key.
- **Manage system prompts**: save reusable instructions (e.g. "Form Assistant", "Summarize", "Translate") and pick one per request.
- **Send content**: select text on the page and send the selection – or send the whole page as a markdown-like extraction. Switch with a toggle.
- **Tool calling on the page**: the model can act on the page itself – fill form fields, click elements, replace text or read content. This enables real workflows like: "Fill the form with the data from my selection."
- **Use results**: copy the answer or insert it directly at the selection. A live log shows every tool call.

#### How it works
1. Open the side panel via the toolbar icon (older Chrome versions automatically fall back to a popup).
2. Add your LLM endpoint under "Endpoints" (templates help).
3. Select text on any website and send it with your chosen system prompt.
4. Watch the tool calls live and insert the answer into the page when needed.

#### Privacy & security
- All data (endpoints, API keys, prompts, settings) stays **strictly local** in your browser (chrome.storage).
- **No data is sent to third parties.** Requests go directly from your browser to the endpoint you configured.
- API keys never leave your browser.
- The extension needs access to all websites ("<all_urls>") to run DOM tools and reach arbitrary, self-configured LLM endpoints.

#### Notes
- Side panel requires Chrome 114+ (permission since 116); older versions automatically use the popup.
- Result quality depends on the chosen model. Local models (e.g. via Ollama) are supported too.
